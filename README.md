Records a Metal frame trace (`.gputrace`) of a shader preset, from a
static image or from a libretro core running a game, for opening in
Xcode's GPU debugger.

## Requirements

- macOS 27+ and Xcode 27+
- Rust 1.98+
- RetroArch.app, only for the RetroArch backend (optional when built with the librashader feature, the default)

## Install

```
cargo install ra-metal-capture
```

From a checkout, `cargo install --path .` builds the same binary.

## Usage

Render an image through a preset:

```
ra-metal-capture \
  --image fixtures/sample.png \
  --shader "$HOME/Library/Application Support/RetroArch/shaders/vectorscale/vectorscale.slangp" \
  --output /tmp/sample.gputrace
```

Run a core with a ROM and a save state, and record the frame after it:

```
ra-metal-capture \
  --core sameboy \
  --rom "path/to/game.gbc" \
  --state "path/to/game.state" \
  --shader "$HOME/Library/Application Support/RetroArch/shaders/vectorscale/vectorscale.slangp" \
  --output /tmp/game.gputrace
```

Do the same in a real RetroArch:

```
ra-metal-capture \
  --backend retroarch \
  --core sameboy \
  --rom "path/to/game.gbc" \
  --state "path/to/game.state" \
  --shader "$HOME/Library/Application Support/RetroArch/shaders/vectorscale/vectorscale.slangp" \
  --output /tmp/game-ra.gputrace
```

`ra-metal-capture --help` lists every flag.

## Backends

### librashader (default)

Hosts the libretro core in this process, or takes the image as the
frame, and runs the shader preset through the
[librashader](https://github.com/SnowflakePowered/librashader) Metal
runtime. The trace is written with Metal's own capture API. No RetroArch
is involved, and nothing is shown on screen.

### retroarch

Launches a RetroArch.app with the core, ROM, state, and preset, and
captures its frames with Apple's `gpucapture`. RetroArch runs on a config
written for the run; your own `retroarch.cfg`, saves, and states are
never written. Available in every build; `cargo install --no-default-features`
gives a RetroArch-only tool.

## Making RetroArch.app capturable

The RetroArch backend needs RetroArch.app to carry the
`com.apple.security.get-task-allow` entitlement, which `gpucapture`
requires of any process it attaches to and which libretro's builds lack.
The tool adds it:

```
ra-metal-capture entitle
```

It asks before re-signing the app ad hoc, and needs running again after
a RetroArch update. `ra-metal-capture entitle --help` lists its flags.
